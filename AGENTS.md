# AGENTS.md

## Principles

Read [contributing/principles.md](contributing/principles.md) before making design or implementation decisions. Every change to the spec, plan, or code should be consistent with these principles.

## Spec

[SPEC.md](SPEC.md) is the target design. Implementation changes move the code toward it. Design changes update it first.

## Plan

[PLAN.md](PLAN.md) is the order of work toward the spec, with an eval decision log. Check off items and log decisions as they land.

## Progress

[PROGRESS.md](PROGRESS.md) describes what is implemented so far. Update it when the implementation changes.

## References

[contributing/references.md](contributing/references.md) lists similar tools and useful material. Check it when designing. Add new sources with their takeaways.

## Documentation

All docs you produce must be:

- **Concise**: say it once, in as few words as clarity allows.
- **Easy to understand**: plain language, clear structure, no jargon without explanation.
- **Kept up to date**: when a change makes a doc inaccurate, update the doc in the same change.
